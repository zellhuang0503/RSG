# RSG 原站比對與最小改動修正方案

日期：2026-09-21

## 本次目標與範圍

使用者要求：以原 WordPress 官網 https://rsg.com.tw/ 為視覺基準，盡可能維持林老師熟悉的圖片、布局、配色、文字與操作。網站搬遷目的是簡化維護、降低外掛依賴，並為 SEO／GEO／AEO 改善建立基礎。本輪先比對與提出修正方案，未修改網站程式，未部署。

實際檢查：原站首頁（桌面與 390px 窄版）、關於花園、一對一催眠、內在小孩課程、最新課程、活動行事曆；對照本機 Astro 首頁、關於花園、催眠、課程頁與各共用模板／內容檔。這是主要版型的比對，不是所有文章逐頁視覺驗收。原站含捲動動畫與延遲載入，截圖中的暫時空白不可直接判定為內容遺失。

## 已量測的原站設計基準

- 桌面 1440px 視窗：Logo 圖顯示約 291 × 91px；白色頁首高約 154px；水藍選單列高約 101px。
- 選單背景 `#85e6f8`；頁尾背景 `#b6f0fb`；版權列與首頁主要標題 `#2b2f56`。
- 首頁區塊標題約 32px，副標約 24px，內文基準約 16px；原站字體為「微軟正黑體」。
- 原站 390px 視窗：頁首約 153px，Banner 約 163px 高；新版相同視窗：頁首約 69px、主視覺 420px 高。新版首屏的圖片比例與資訊密度明顯不同。
- 以上是本輪量測的還原參考，不宜將桌面固定像素直接套到所有螢幕；手機仍需檢查圖片文字、選單展開及捲動。

## 執行順序

1. **全站頁首、頁尾、色彩與字體，加上首頁還原**：先完成最直接影響辨識度的部分；在本機與原站同尺寸比對。
2. **主要內頁專用版型**：關於、服務、最新課程及課程介紹；保持內容檔可編輯，將布局放在模板。
3. **行事曆及功能核對**：月份切換、課程導覽、預約、會員登入、手機選單、影片、搜尋。
4. **搜尋與搬遷檢查**：保留原有網址、轉址、標題與內文；核對 canonical、結構化資料、sitemap、圖片替代文字與內部連結。這些項目可在保留外觀的前提下處理，不承諾流量一定成長。

主要實作檔案：`src/components/Header.astro`、`Footer.astro`、`src/styles/global.css`、`src/site.ts`、`src/pages/index.astro`、`src/pages/[...path].astro`、`src/pages/events.astro`；新增少量專用版型與集中管理的首頁海報資料。

輪播使用輕量前端程式，應支援前後切換、鍵盤及暫停自動播放；保留圖片原本的構圖與文字。服務與預約文案沿用原站，不在布局修正中改寫。外部商店與能量卡維持原入口。

## 驗收界線

- 林老師熟悉的 Logo、六張 Banner、海報、首頁閱讀順序、配色與文案應可直接辨認。
- 同尺寸對照首頁與每一種主要頁型，包含 390px 窄版與桌面版。
- 檢查活動跨日、月份邊界、搜尋、輪播控制、選單、圖片及外部連結。
- 原站動畫的暫時空白、外掛殘留和失效連結不當作應復刻的設計；發現時分列為修復事項。
- 本輪沒有變更 WordPress、DNS、Cloudflare、商店或正式站內容。
