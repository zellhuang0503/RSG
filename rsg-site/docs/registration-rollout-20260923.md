## 後續維護

1. `registration-courses.json` 登錄課程 ID 與路徑；文章 `presentation.registrationCourseId` 需一致。
2. 場次以 D1 `course_sessions` 為線上執行時來源，JSON 為首批資料與未部署 D1 時的唯讀顯示。`priceNote` 可表示食宿等費用附註，表格、確認畫面與信件一致。
3. 新增場次使用新的 migration。此次 `0003_group_course_sessions.sql` 只 INSERT OR IGNORE 第五期，不修改已有試作資料／申請。日後可用 `npm run registration:seed -- 0004_new_sessions.sql` 產生新檔，工具拒絕覆寫已存在的 migration；修改既有場次須另寫明確 UPDATE。
4. 新一期日期、價格、截止日與名額需課務確認；不能把舊費用套成未來的新期費用。目前兩個場次截止日預設上課當日台北時間 00:00，正式上線前仍待課務確認。
5. Cloudflare 正式 D1、Turnstile、Workers Secrets、通知排程與受保護的課務管理介面，依 pilot 文件完成後另行部署。此次「套用」不等於已正式開放報名。
