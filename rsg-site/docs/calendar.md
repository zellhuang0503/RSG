# 課程行事曆

- 資料沿用 `content/events/*.md` 的 `start_date`、`end_date`、`all_day`、`venue` 和原網址。無開始日期不推測、不使用文章發佈日補日期。
- `EventCalendar.astro` 是共用元件；`calendar.css` 統一樣式，`scripts/calendar.ts` 負責切換及互動；`lib/calendar.mjs` 集中日期、篩選與跨月規則。
- 以台灣時間判斷今天。預設當月、週一至週日，前往月份不能早於本月。跨日課程逐日顯示，但月份場次只計算一次。
- 只顯示進行中及即將開始的活動。建置時先排除已結束資料，瀏覽器開啟時再篩選；開著的頁面每分鐘及回到分頁時檢查日期／到期變化，有變化才更新。
- 全天活動包含結束日整天；有結束時間的活動過時即排除；缺少結束時間時保留至開始日結束。過去日期格子不列活動。
- 手機保持可橫向滑動的月曆，可切換日期清單。日期清單依本月篩選，不恢復舊資訊卡片或歷史年份區塊。
- 無 JavaScript 時提供建置當下尚未結束的純文字日期清單；自動到期篩選需要 JavaScript。歷史活動內容頁仍保留原網址。
- 驗證：`node --test tests/calendar.test.mjs`（在 rsg-site 執行），再 `npm run build`。
